## What This Covers

This video walks through all three artifacts before enhancement, covering:

- **Software Design and Engineering** — the 3D OpenGL scene from CS 330: existing functionality, code review findings (a GPU memory leak, an always-true material lookup, duplicated camera logic), and the planned enhancement.
- **Algorithms and Data Structures** - the Rescue Animal Management System from IT 145: existing functionality, code review findings (a Scanner bug, a broken reservation check, a scrambled constructor call), and the planned enhancement.
- **Databases** — the Android inventory application from CS 360: existing functionality, code review findings (no actual encryption despite the artifact's name, plaintext password comparison), and the planned enhancement.

Each section follows the same structure: a walkthrough of what the existing code does, an analysis using standard code review criteria (structure, efficiency, security, error handling, documentation), and an explanation of the planned enhancement tied to specific skills and course outcomes.
